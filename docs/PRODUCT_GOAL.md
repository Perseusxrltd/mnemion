# Mnemion product goal

Clarified at Quentin's request on **31 October 2026**. This wording preserves
the full requested scope and the requirement for **100% complete, fully working,
professional release readiness**. It does not claim the goal has been achieved.

Deliver Mnemion as a complete, professionally reliable memory infrastructure
product for individuals, teams and organizations across AI assistants, agents,
applications, devices, and Windows, macOS and Linux. Complete the entire scope
in the [product requirements](PRODUCT_REQUIREMENTS.md), [roadmap](ROADMAP.md),
[repository study and rebuild map](research/2026-10-09-mnemion-study/README.md),
GitHub issues and subsequent user instructions. Preserve useful existing
features and every unfinished requirement.

Provide simple end-to-end app onboarding and equivalent native agent control;
secure, compartmentalized and recoverable shared workspaces and vaults with
independent administration; interoperable local, cloud and Git sources and all
requested connectors; an intelligent layered librarian with configurable
embedding and local/cloud model choices; Obsidian compatibility; visual memory
maps; useful evaluations, statistics and anonymous user-controlled telemetry.

Keep the [whole product light](implementation/runtime-efficiency.md) while idle
or in the background. Adapt resource use to available hardware and user/agent
budgets, load models on demand, prioritize useful foreground work, and perform
expensive maintenance only when needed.

Ship working installers, safe default automatic updates, background/boot
operation and recovery on every supported target. Keep main current, the public
repository clean and safe, and in-app/Git documentation, the live Perseus XR
product page, downloads, release notes and roadmap synchronized automatically.
Keep Mnemion **100% free**, use a free release/operating pipeline within the
no-spending instruction, and make financial support optional.

Completion means the full requested product is implemented, documented,
released and verified through real user and agent journeys, including security,
data integrity, recovery, platform compatibility, updating and whole-product
efficiency. Partial features, unresolved defects and external prerequisites
remain open. No requirement may be dropped, narrowed, relabeled or treated as
complete merely to reach 100%.

The requirement inventory and its acceptance evidence remain authoritative.
This clarification retains all **66 requirements** and their current states;
it does not reset progress, replace the current milestone, or cancel work
already underway.
