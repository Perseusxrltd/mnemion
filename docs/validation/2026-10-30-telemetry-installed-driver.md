# Installed telemetry diagnostic source qualification

30 October 2026. Grok's installed delivery driver was reviewed and integrated
with the browser admission correction. The third installed run below
qualifies scoped delivery on three targets; the full matrix remains unqualified.

The driver builds an unpublished copy with one disposable localhost TLS
certificate. The normal app entry, bridge and delivery owner stay in use.
Windows ARM imports the diagnostic x64 engine built from the same source and
certificate. No private key enters the source copy, package or public release.

The journey exercises real save, fetch and lexical recall, reviews a report,
checks its received bytes and spent budget, then checks opt-out and manual
review after one restart. Packaging runs without blocking the local collector.
Failed process or database cleanup prevents a successful receipt.

The focused local qualification passed 21 fixture checks, the installed smoke
script's syntax check and the Electron build. Original Grok candidates are
`6d9c9a18` and corrected `42808919`; Astra's integrated source is `696182b2`.
The original logs are retained under
`telemetry-installed-delivery/astra-source-checks/` in the private automation

The manual `Installed telemetry delivery` workflow runs the journey on all six
native targets. It retains diagnostic evidence and does not publish installers.
Source checks alone do not establish installed delivery, resource acceptance
or production ingress; actual target results are recorded below. Production
collection, its destination and its route remain disabled/unconfigured, and
V08 remains Building.

## Second installed run and report readiness

[Run 41006912127](https://github.com/Perseusxrltd/mnemion/actions/runs/41006912127)
used source `2053fa9f6f51f28914af97d2e8d0574a72cdb8c2`. All eleven prerequisite
jobs passed. The six installed apps reached the memory API, then stopped before
delivery: Windows x64/ARM64, Linux x64 and macOS ARM64 waited for a held report;
Linux ARM64 and macOS x64 encountered a null review snapshot while checking
manual mode. No report was received. Original package hashes and failures are
retained.

Astra found a diagnostic ordering error: `review_status` is read-only and its
`report_available` field describes an already held report. Normal producer
observations enter `pending`; **Inspect next report** creates the held report
from those rows. Waiting for a held report before clicking Inspect cannot test
first-report staging. The failed run did not retain a pending-count snapshot,
so it does not establish whether producers staged observations successfully.

Grok correction `29db8646` waits for a coherent permitted/manual-review snapshot
with pending observations, refreshes the privacy UI and uses its normal Inspect
control. A small shared diagnostic helper handles null snapshots and retains
only allowed phase/gate codes. Three focused Node cases passed; production
ownership and admission are unchanged. The next installed run must qualify the
corrected ordering and the UI readiness follow-up, including final opt-out and
restart. No successful installed delivery follows from these source checks.

The UI readiness follow-up (`31c9a0e9`) refreshes Privacy after native state is
ready, then waits for the normal manual-review checkbox to become visible and
enabled. A native read alone does not refresh the page's earlier null snapshot.
Astra reviewed both changes and built the Electron bridge once successfully.
The three unchanged focused cases were not repeated. The next six-target run
must establish actual staging and delivery; the original failures remain.

## Third installed run: three scoped passes

[Run 41013868878](https://github.com/Perseusxrltd/mnemion/actions/runs/41013868878)
used source `c8f75870ca0c3df1e8bd4af5e4456a403f80bbba`, original attempt 1.
Linux x64 and both Macs passed scoped installed fixture delivery. Each recorded
21 successful memory API calls and one inspected/approved 25-byte report matched
by the collector. Final opt-out and manual-review mode survived the second app
launch. Each retained one spent reservation `[1, 65536]`, a cleared lease, an
empty queue and no fixture content in the store.

Windows x64 and ARM64 failed `memory_observations/no_observations`, with 8 and 9
successful API calls respectively and zero reports. Linux ARM64 failed
`before_permission/connection_pending`, with 3 successful calls and zero reports.
These original failures remain alongside the first two runs; overall installed
qualification has not passed.

The source exposes a connection-control race: the driver observes committed
native manual-review state, then changes the select without waiting for it to
be enabled. React can still be busy completing the preceding control request;
`choose()` ignores changes while busy. Waiting for the real enabled control
before the single change preserves the subsequent stored-state check. This is
a source-grounded race, not proof that every connection failure has that cause.

The Windows drop cause remains unproven. Real producer admission has a 25 ms
snapshot deadline, while a Windows store open performs a fresh native ACL
check. Late snapshots, storage contention, negative hints or stale stamps can
drop optional observations without failing memory actions. The original failure
artifacts lack producer timings/refusal categories and cycle ordinals. Bounded
diagnostics are pending; a longer readiness wait cannot recreate dropped
observations, and no consent, ACL or resource gate is bypassed.

Astra matched all six original artifact digests to retained metadata. For the
three passing targets, runtime/platform, packaged 4.46.57 identity, installer
hashes and source inventories agree; the tracked-source digest was recomputed
from the original Git commit. Installer binaries are not retained for independent
rehashing. Collector equality was checked live by the source-bound driver; no
separate raw collector packet is retained for replay comparison. These limits
remain explicit. No full installed, production-ingress, resource-budget or full
V08 acceptance follows from the three scoped passes.
