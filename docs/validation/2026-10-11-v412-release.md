## Actual Windows installation

The existing Windows x64 installation also upgraded from 4.0.11 to 4.0.12 using
its built-in updater. **Check for updates** was selected at 22:35:10 UTC;
**Restart to update** was selected at 22:36:50 UTC after verification finished.
The original process exited and the installed 4.0.12 process started at
22:37:54 UTC. Automatic updates, background operation and login startup remained
enabled. No installer was launched manually and no update guard was weakened.

This specific observation includes **manual discovery and a deliberate safe
restart**. It is distinct from the public automatic rehearsals and the earlier
unattended Windows 4.0.9 → 4.0.10 observation. The updated native app joined the
original live workspace through its normal form with an individual human
administrator. A subsequent normal quit/reopen authenticated the saved
OS-protected connection without entering the key again. Workspace hosting and
the remote server version are independent of a desktop update.
