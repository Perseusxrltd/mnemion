# Native memory diagnostics — 31 October 2026

These are developer diagnostic prototypes. The standalone Windows SDK measurement and corrected macOS helper and Linux BPF builds have passed. The first macOS and Linux compilation failures remain recorded. These results do not close product issues or qualify application resource budgets.

**Windows SDK.** [Run 41237380248](https://github.com/Perseusxrltd/mnemion/actions/runs/41237380248) measured identical SDK layouts on native x64 and ARM64, apart from the architecture identifier. The [SDK validation note](2026-10-31-windows-sdk-abi.md) retains the exact source, original JSON and earlier failures. The [standalone tool](../../deploy/windows_sdk_abi/README.md) measures C structure sizes and offsets. Those measurements remain valid for the measured fields. A draft FFI comparator can falsely pass without SDK measurements for the used `EVENT_HEADER_EXTENDED_DATA_ITEM` layout, so comparison acceptance is withheld pending expanded SDK measurements and a stricter success criterion. Controlled ETW lifetime measurements remain a separate gate.

**macOS helper compilation.** [Run 41239575056](https://github.com/Perseusxrltd/mnemion/actions/runs/41239575056), source `df524c9f004b98e61695162fb3bf912a86c4730d`, failed on `macos-26` ARM64 and `macos-15-intel` x86_64. The [build and admission notes](../../deploy/linux_bpf_lifetime/BUILD.md) describe the remaining kernel/BTF admission, verifier/load checks, lifetime census and peak validation, and external cleanup proof.
