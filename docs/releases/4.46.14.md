# Mnemion 4.46.14

**Unpublished candidate.** This source builds on published 4.46.13 with optional
exact report review and more portable local telemetry admission controls. See
automatic [release status](../RELEASE_STATUS.md) for availability; no installed
or public acceptance is claimed for 4.46.14.

The app and local CLI/MCP controls can select **manual report review before
granting permission**. Once authorized observations exist, inspection holds one
exact four-byte report without spending delivery allowance. Repeated inspection
keeps its bytes and original expiry, limited to 15 minutes or earlier observation
expiry. Approval permits one eligible attempt with fresh policy and lifetime
checks. Discard or expiry never resumes automatic sending; automatic remains
the default until manual review is selected. The synthetic read-only format
example remains available separately. See the [review behavior and source
evidence](../validation/2026-10-26-telemetry-report-review.md).

Private clock readers keep Python and native review lifetimes consistent.
Headless Python can use the same OS clock without a compiler when the packaged
helper is absent; a present broken helper is never bypassed. Browser review
clocks live only among open tabs. These local control values are never telemetry
identifiers. Linux, Windows x64 and both Mac architectures have scoped component
evidence; full installed review remains unqualified.

On Linux and macOS, [CPU admission](../validation/2026-10-26-telemetry-cpu-admission.md)
reads aggregate counters without enumerating per-core details, retaining the
existing pressure threshold and sample-validity checks. Windows source installs
can [read the documented local network-cost hint](../validation/2026-10-26-telemetry-headless-network.md)
when the packaged helper is absent. Unknown metering still blocks automatic
delivery, and explicit connection choices cannot override detected restrictions.
These changes do not establish lower whole-app resource use.
