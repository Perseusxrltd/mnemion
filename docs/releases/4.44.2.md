# Mnemion 4.44.2

Codex CLI 0.163 conversations now include their completed user and assistant
messages in readable transcripts. Repeated spoken messages remain separate
turns; duplicate response copies, private context and non-text items are omitted
from the readable projection. Earlier Codex message formats remain supported.

Live conversation connections re-examine log prefixes that the older parser
skipped. Unchanged conversations keep their stored revisions, while corrected
readable content receives a new revision. Existing source and conversation
identities and the v1 projection format remain compatible.

This patch uses the existing file-mirror connectors. Durable L1 retained capture
remains separate work. It also carries forward the startup shutdown, native
crypto initialization and Windows atomic-settings fixes prepared for 4.44.1.

The [compatibility validation](../validation/2026-10-21-codex-compatibility.md)
records 66 passing source checks, including real Codex fixtures through HTTP and
PostgreSQL. Current platform results and availability are recorded in the
[live release status](https://github.com/Perseusxrltd/mnemion/blob/main/docs/RELEASE_STATUS.md)
and [published releases](https://github.com/Perseusxrltd/mnemion/releases).
