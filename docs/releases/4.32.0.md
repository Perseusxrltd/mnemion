# Mnemion 4.32.0

Connect a local agent from **Agents → Connect an agent on this computer**.
Choose the client, its dedicated application and a connection name, review
the exact configuration, then install. Administrators can create the dedicated
key in that flow. Codex, Grok Build, Claude Code/Desktop, Cursor, Gemini CLI,
Zed, Devin Desktop, legacy Windsurf and explicit generic MCP files have profiles.

Existing client policies and other servers remain intact. Replacing a named
entry needs separate confirmation and creates a private backup. Concurrent
file changes invalidate old previews. Different workspaces can use independent
connection names and scoped application identities.

The private launcher uses a verified copy of Studio's bundled engine, without
an additional Python installation or model download. It keeps working after
Studio closes, including with a Linux AppImage. Studio refreshes that copy after
its updates; existing agent sessions retain their current files until reopened.
Inactive old runtimes and interrupted copies are cleaned automatically.

**Agent connections on this computer** shows the actual installed state and
allows removal while signed out. Four private local-agent operations provide
the same preview, installation, inspection and removal. Settings mutations and
runtime refreshes participate in guarded app updates.

Windows now retries brief file locks while atomically saving local status.
Permanent denials retain existing data and show a specific file-permission
message. This fixes the backup-status failure caught in the unpublished first
candidate; it does not repeat a backup or change private file permissions.

Standalone keys live in files restricted to the current OS account, separately
from Studio's encrypted login/source store. Configuration includes only the key
file's path. Removal preserves externally edited entries and does not revoke
server keys or affect other devices. Use dedicated application permissions and
revoke keys when retiring a device.

Configuration support does not claim a vendor has loaded its tools or enabled
conversation capture. Hosted ChatGPT acceptance and separate Grokbot/Dot/Hermes/
OpenClaw packaging remain on the roadmap. No database migration or dependency
is added.
