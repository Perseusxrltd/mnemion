# Mnemion 4.46.19

App preference acknowledgements now say whether a change was actually saved.
Telemetry reports a failed save as a failure for both menus and native agents.

Explicit application/tray update controls and standalone capture controls now
use the existing privacy rules and reviewed action categories. Capture status,
previews, private-key generation, managed children and reusable helpers remain
excluded. Interrupted or uncertain operations are not replayed for measurement.

Explicit `prepare-model` and `librarian-models --prepare` commands now have
their own preparation observer. It receives only the fixed preparation kind;
model/profile identifiers and normal command output stay outside telemetry.
Listing, registry helpers and automatic deployment/startup preparation acquire
no owner. The privacy inventory now declares **87 mapped categories and seven
unmeasured**, preserving the earlier 86/eight audit as historical evidence.
Model resource/sensor qualification and the other action gaps remain open.

Installed-app model diagnostics now retain the failing operation and a closed
error category without publishing raw exceptions or private data. The original
4.46.17 Mac ARM failure remains under diagnosis; this change does not claim to
repair its unknown cause.

Source validation: **64 Python, 24 distinct Electron/agent and 25 browser-source
checks passed**, plus **eight earlier focused checks** for diagnostic retention.
Electron builds passed, as did the final frontend build. Local preparation
tests use stubbed registries and methods; they performed no inference or model
download.

A separate focused Mac ARM installed journey passed on **package 4.46.18,
source `95c2000c`**, including a real model download. It did not reproduce the
earlier failure, whose cause remains unknown. That older-source result does
not qualify this newer 4.46.19 batch. Native release qualification and
publication remain separate; see
[current release status](../RELEASE_STATUS.md).

Product telemetry remains **Building and inactive**. No production collection
endpoint is enabled. Full privacy, resource, utility and platform acceptance
remain on the [roadmap](../ROADMAP.md) and
[telemetry contract](../implementation/anonymous-product-telemetry.md).
