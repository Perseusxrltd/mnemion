# Mnemion 4.38.0

Connect Hermes and OpenClaw from Studio, and download Perseus XR connection
packages for OpenAI/Codex, Claude Code, Grok Build, Hermes, OpenClaw and Grok Bot.
The package type is explicit: Grok Bot receives a connection guide; Hermes and
OpenClaw receive native configuration; supported plugin targets receive their
own manifests. Sign-in and provider acceptance remain separate.

- **Native local setup:** Hermes YAML and OpenClaw's nested JSON5 configuration
  join the existing app and agent installer. Explicit homes, profile/config paths,
  named workspaces, private keys, backups, reopen/status and removal are supported.
  Hermes retains comments and quotes; OpenClaw JSON5 is saved as ordinary JSON
  with its exact original backed up.
- **Connection packages:** app, HTTP API, SDKs, agent catalog and standalone
  `agent-package` command share a bounded generator. Exports contain the chosen
  HTTPS MCP address, instructions, version and canonical logo, without embedded
  credentials or personal app IDs. Every package is authored by Perseus XR.
- **Configuration safety fixes:** duplicate JSON/JSON5/YAML keys are rejected
  before replacement; editing an aliased YAML MCP section preserves other
  settings; unchanged connections retain their exact files. Native file selection
  recognizes YAML and JSON5. Claude packages remain compatible with the observed
  older client that rejects the newer directory icon field.
- **Acceptance and documentation:** actual signed-in ChatGPT OAuth, 16-tool
  discovery and a profile-only request completed issue 18. New real-deployment
  issues 44/45/46 retain their cloud-client, guarded-upgrade and office-access criteria.
  A paused upstream note publisher must remain distinguishable from a healthy
  API or native journal.

The [expanded librarian study](../research/2026-10-20-layered-librarian.md) adds
a concrete research-backed roadmap for raw capture, layered consolidation,
statistical resurfacing and an optional Jev decision stage. These are planned
capabilities, distinct from the current bounded librarian.

No database migration is introduced. Existing application keys, consent and
workspace grants retain their authority. Existing clients can continue using
their current setup. See the [package guide](../service/agent-packages.md),
[local installer](../service/desktop-agents.md) and
[dated validation](../validation/2026-10-20-native-connectors.md) for tested
behavior and remaining provider/deployment acceptance.
