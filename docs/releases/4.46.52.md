# Mnemion 4.46.52

Automatic desktop updates preserve background operation when **Keep running in
background** is enabled. A restart requested from the visible app returns to
that window; a requested restart from a hidden or minimized app stays in the
background. Linux retains a minimized taskbar window for easy reopening.

The [relaunch correction](../validation/2026-10-29-background-relaunch.md) uses a
small, one-use record for the exact new version. Missing, stale or invalid
records retain normal startup, and a failed installer handoff clears its
record. All existing work, inactivity, administrator and installer-verification
checks remain in force. Focused checks passed on Linux and Windows; native
installation and publication are tracked separately in
[release status](../RELEASE_STATUS.md). Older updater versions cannot write the
new record, so their first update to this version is not retroactively fixed.

The [update guide](../service/updates.md) now explains check timing and status,
and the [footprint record](../implementation/installer-footprint.md) includes
the public 4.46.49 download sizes: approximately 220–271 MB. The 400 MiB installer
ceiling remains unchanged. The backup-reader and telemetry-report fixes from
4.46.51 are included. Full telemetry acceptance and GitHub issues 44, 47 and 48
remain open; production telemetry collection remains disabled.
