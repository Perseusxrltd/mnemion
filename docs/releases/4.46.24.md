# Mnemion 4.46.24

Capture telemetry now distinguishes cycles that only deliver previously captured
items. No locally accepted items plus a positive verified fresh stored count
selects `capture.deliver`; accepting local items stays `capture.collect`. One
original policy/generation snapshot owns the cycle, preserving its outcome and
whole-cycle latency. Completed cycles without fresh work remain suppressed;
incomplete/denied outcomes and unknown-count handling are preserved. Mixed cycles
gain no second owner, and saved history is not converted into fresh usage.

Explicit native/app conversation preview and standalone `--capture-control`
action `preview` now own `capture.preview`. Standalone capture pause owns one
`capture.pause` acknowledgement. The separate `--inspect` path, status, polling
and reusable helpers remain unowned. Telemetry does not copy preview content,
paths or source identity.

Product checks also gain the existing single retry for a first-attempt job that
GitHub explicitly confirms never acquired a hosted runner. The latest eligible
`main` push CI must still match current runtime source, allowing only the existing
documentation/metadata scope to advance. Complete capacity evidence is required,
and run/source eligibility is rechecked before the request. Newer CI, ordinary
test failures and incomplete evidence prevent a retry; failed checks do not
qualify a release.

[Source validation](../validation/2026-10-26-telemetry-capture-actions.md) passed
109 distinct capture Python cases, 154 Node desktop/store cases with two
Windows-only skips, 120 browser-source cases and 41 separate mocked capacity-guard
tests. Frontend and Electron builds passed. Three initial Python failures and
one initial Node failure are retained with test-only corrections for re-enable
generations, observation limits and contention/one-claim expectations. Those
corrections did not change runtime behavior.

The inventory contains 94 categories: 91 mapped and three unmeasured
(`workspace.switch`, `backup.list`, `update.verify`). Its 630 declared actions
and fixed variants comprise 356 mapped, 267 excluded and seven delegated rows.
Declarations do not establish complete interface, sensor or installed coverage.

V08 remains **Building and inactive**: collection is unavailable, destination and
route are null. Catalog, disclosure, metric coordinates and wire views are
unchanged. All 66 requirement texts and existing resource/privacy limits remain.
Resource, whole-wire/provider/ingress privacy and installed-platform acceptance
stay open. Source checks are separate from native qualification and publication;
see [release status](../RELEASE_STATUS.md) for current availability.
