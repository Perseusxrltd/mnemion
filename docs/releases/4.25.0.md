# Mnemion 4.25.0

The frozen 4.25 candidate was **withheld** after the six installed-host checks
selected a textarea on the previous page during navigation. The importer and
the corrected editor check are carried into [4.26](4.26.0.md). Use the automatic
[release status](../RELEASE_STATUS.md) for public availability.

Older agent buffers now have a reviewed recovery path in Studio, the Python and
TypeScript clients, HTTP and private agent controls. Complete legacy JSONL records
are reconciled into a private native space with stable identities, original
writer/time provenance, immediate keyword search and normal writable memories.

Duplicate lines are combined; conflicting source IDs require review. Repeating
an import preserves later edits and quarantine. Explicit withdrawals, including
IDs never imported, and ordinary native deletions prevent older copies from
resurrecting those records. Every batch commits atomically with its indexing
work and receipt. Current access and destination state are checked again before
application. Secret checks remain mandatory; personal-data checks default on.

The [recovery guide](../service/legacy-buffer.md) explains limits and the encrypted
source boundary. Imports cannot target a shared or source-bound space or one with
a Git publication policy, even when paused. Source recovery does not restore
missing database history, accounts, secrets or original remote acknowledgments.
Later sharing/publication remains an explicit decision. This advances issue 39;
complete native-journal reconstruction and original-office recovery remain open.

Release maintenance also gains one automatic retry when GitHub explicitly fails
to acquire a hosted runner before any step starts. Actual test failures and
second attempts remain for investigation. The automation reuses successful jobs
and preserves the normal public-release gates.

No schema migration or new dependency is required. Native release availability
and installed automatic-update results remain visible in the
[release status](../RELEASE_STATUS.md). The [focused evidence](../validation/2026-10-19-legacy-buffer.md)
records 45 passing cases, 25 migration checks and the actual app import/review.
