# Mnemion 4.46.20

The telemetry format preview now includes **Individual actions**, with search,
source/state filters, fixed exclusion reasons, delegation and pages of 50 rows.
It shows when a declared interface action has no reviewed measurement mapping,
even if another action already maps to the same category. Inspection remains
read-only and adds no collection owner, sensor or producer.

The source inventory contains **525 actions and fixed variants: 296 mapped,
224 excluded, five delegated and zero unmeasured among these declarations**.
Four shipped interfaces are independently enumerated; other owners use reviewed
source-route maps. Category coverage remains **87 mapped and seven unmeasured
out of 94**. These counts do not establish coverage of every screen, call site,
sensor or installed interface.

Source validation: **22 distinct Python, 16 Electron/bridge and 42
browser-source/client checks passed**, along with source builds and 4.46.20
preparation. The generator recheck overlaps the Python total; the Electron
total includes two Node-to-Python bridge cases using compiled desktop controllers.

Actual Chrome verification passed with **eight evaluated observations** for
pagination, search, exclusions, delegation, empty states and refresh clearing.
Browser storage stayed empty, no report or foreign requests were observed,
the console was clean, and browser/server cleanup was verified. This journey
used changed compiled assets based on `93eb300`, with package 4.46.19 metadata
before 4.46.20 preparation. It does not qualify an installed native release. See the
[action-preview report](../validation/2026-10-26-telemetry-action-preview.md)
for the recorded source boundaries and limitations.

All 66 requirement texts remain retained. Full interface, resource, privacy,
utility and installed-platform acceptance remain open. Native release
qualification and publication remain separate; consult
