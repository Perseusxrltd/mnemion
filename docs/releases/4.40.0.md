# Mnemion 4.40.0

See how much of a space the librarian has processed, export its measured usage,
and let local agents inspect the inactivity hold on a downloaded app update.

- **Librarian coverage:** separate organization and review charts show completed
  responses, skips, attempts and waiting revisions for the saved model profile.
  Changed and unseen memories, the oldest waiting revision and withheld records
  are explicit. Completing a response does not certify its conclusions.
- **Processing statistics:** inspect 30-day calls, request/response bytes,
  provider time and run outcomes. Download the JSON from Studio or read the same
  data through the authenticated API, Python/TypeScript SDKs and agent contract.
  The query requires current reviewer access, reads no memory text and makes no
  model calls. The layout supports desktop and narrow windows.
- **Update diagnostics:** `app.status` now exposes OS idle seconds and the
  remaining inactivity requirement. Agents can distinguish continued activity
  from a failed download. Draft, transfer, focus and administrator safeguards
  retain their existing behavior; unavailable OS measurements are reported as
  unknown.
- **Research and operating documentation:** record the successful first weekly
  research workflow and the next layered-librarian milestone without claiming
  autonomous consolidation or model accuracy from processing counters.

No new database migration is required after 4.37. These additions do not require
a paid model or an account. Separate Grok Bot cloud acceptance, source-host
permission revalidation and the intentionally paused PC publisher remain
tracked in issues 44–46; this update does not mark those deployment tasks done.
