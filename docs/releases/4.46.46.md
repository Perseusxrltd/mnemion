# Mnemion 4.46.46

Desktop packaging now uses balanced lossless compression. Mac disk images and
update ZIPs previously selected uncompressed storage; all application components
are retained. The existing installer verification also reports unpacked component
sizes, so future releases expose size changes automatically in their build receipts.
The native builds determine the resulting download sizes. See the
[footprint measurements and remaining work](../implementation/installer-footprint.md).

Agents can inspect permitted vault metadata through MCP while secret-value tools
remain disabled. A host operator opts into metadata access, and an organization
administrator can grant a specific key access to credential names, IDs, versions
and the vault audit log. Each grant has a revision and optional expiry; it gives
no permission to read, change, export or delete secret values.

The app has separate host setup controls and a **Secrets → Metadata auditors**
page. The same administration is available through the API, both SDKs and the
agent operation catalog. Metadata remains available for key repair when the
vault API is enabled. Disabled or expired keys and disabled owners lose access;
restoring a backup disables historical auditor grants until they are reviewed.

Existing host settings remain unchanged during upgrade. Older local configuration
files remain supported, and an omitted metadata setting preserves its saved value.
This addresses the vault-access portion of issues #47 and #48; their remaining
field acceptance and format interoperability work stays open.

The [source qualification](../validation/2026-10-28-vault-metadata.md) covers 49
Python cases, 22 SDK tests, 70 desktop controls and the actual app grant/inspect/
revoke journey. Earlier assertion and browser-selector corrections are retained.
The new controls also have their reviewed telemetry ownership declarations;
16 focused Python checks and 24 Studio measurement checks cover that correction.
The auditor migration also preserves the existing KeePass preview/import/export
audit actions. Fifty focused PostgreSQL cases cover that correction, including
upgrades of existing histories and the new auditor permissions.
Release publication and all-platform installation qualification are pending. Anonymous product telemetry
remains under implementation, with production collection disabled.
