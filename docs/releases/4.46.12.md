# Mnemion 4.46.12

Privacy controls now show a clearly labeled, fixed four-byte report-format
example. The app and native agent expose the same format without changing
consent, pending counts or sending allowances. Refreshing privacy settings or
changing a choice clears the old preview. Configured transport capability is
reported separately from permission to collect.

Local backups reuse their authenticated workspace-identity connection to
estimate required disk space. This removes the additional connection that timed
out during the Windows 4.46.11 candidate's first backup. TLS/process/tenant
verification, disk checks and existing deadlines remain in place. Installed
failure reports now preserve the classified backup diagnostic. The cause of
the original intermittent timeout has not been established.

This candidate also carries the unreleased corrections recorded in
[4.46.7](4.46.7.md), [4.46.8](4.46.8.md), [4.46.9](4.46.9.md),
[4.46.10](4.46.10.md) and [4.46.11](4.46.11.md). The installed gate adds actual
privacy-page and agent-control checks, including opt-out persistence across
restart, alongside the existing memory, backup, recovery and update journeys.

Product telemetry remains **Building and inactive**. The format example does
not inspect the actual next packet. Production collector qualification,
resource acceptance and the remaining privacy/delivery conditions are still
open. All 66 product requirements retain their scope and states.

Validation: 10 PostgreSQL backup checks, 18 desktop backup/diagnostic checks,
106 Python telemetry checks, 82 browser telemetry checks and nine native
control/wire checks passed; frontend and Electron builds passed. These focused
results do not replace the required release matrix. See the
[backup evidence](../validation/2026-10-26-windows-backup-connection.md) and
[preview evidence](../validation/2026-10-26-telemetry-preview.md).
