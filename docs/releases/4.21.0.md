# Mnemion 4.21.0

This update addresses [issue 43](https://github.com/Perseusxrltd/mnemion/issues/43):
one malformed text file could suspend an entire folder source, preventing
unrelated notes from updating while the service still reported ready.

- Folder, Git and rclone text scans isolate invalid UTF-8, binary text and files
  over the configured size limit. Valid files continue syncing. The app's
  **Connections → Source status** lists affected relative paths and reasons.
- Partial scans keep the last good data, retain stable memory identities and
  withhold missing-file deletion, the complete checkpoint and requested-sync
  acknowledgement. A later clean scan reconciles the inventory normally.
- Search and context warn about incomplete inventories and unavailable sources
  in the caller's selected access scope. `GET /v1/health/sources`, the Python and
  TypeScript clients, and agent operation `health.sources` expose scoped counts.
  Authenticated `/health/ready` includes the same attention signals; anonymous
  readiness explicitly reports that source health was not checked.
- Diagnostics contain at most 50 relative paths plus stable path hashes and the
  total skipped count. Private content, source ACLs and other users' sources are
  not returned in health summaries.

Upgrade the **server and source runners**. Migration
`024_source_health.sql` adds a lookup index and a grant-scoped health function;
it does not rewrite memories or require re-embedding. Back up before migration
and use the normal coordinated upgrade process. A new runner detects whether
the server supports partial inventories; an older server retains the previous
fail-closed behavior and receives `text_source_server_upgrade_required`.

Directory, access, symlink and incomplete-provider-inventory failures still
suspend the affected scope. Unreadable JSON/JSONL and incomplete Git journals
also remain fail-closed: skipping a catalog or denial could revive withdrawn
evidence. Use the [live conversation adapter](../service/live-conversations.md)
for changing agent transcripts. Invalid text is never silently decoded with
replacement characters or written back to the original file.

[Validation](../validation/2026-10-19-source-health.md) distinguishes source
checks from native release, publication and public-update acceptance. The
[release status](../RELEASE_STATUS.md) and
[product page](https://www.perseusxr.com/mnemion) track verified downloads.
