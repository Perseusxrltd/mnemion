# Mnemion 4.46.42

Publication now allows a short wait for GitHub's uploaded-byte verification
job metadata to become visible. Missing or pending metadata is polled within
a 60-second window; failed, skipped, ambiguous or erroneous responses still
stop publication. Receipt, inventory, signature and source checks remain in
force, and publication writes are not automatically retried. The
[publication-status report](../validation/2026-10-27-release-publication-status.md)
retains the original v4.46.39 failure and its separate successful recovery;
the original metadata delay remains an unproven explanation.

Native telemetry now reads current preference metadata in one fixed SQL
statement and uses bounded array snapshots for pending rows. Legacy schema
handling and fresh private-file, company-policy, consent and final-send checks
remain authoritative. No positive permission or database handle is cached
across transactions.

Node 22.22 Linux source checks and 38 publisher tests. The Electron build passed;
the native source group was not rerun. These checks do not qualify an actual
Electron app journey or establish RAM/CPU savings. The
[SQL-read report](../validation/2026-10-27-telemetry-sql-reads.md) retains the
input bindings, failed resource history and planned comparison without a result.

Production product telemetry remains **disabled** and V08 remains **Building**.
All 66 requirements and the **2 MiB RSS / 0.5% CPU** ceilings remain unchanged;
resource, provider/privacy, installed/platform and full telemetry acceptance
are still open. The [release status](../RELEASE_STATUS.md) owns public availability.
