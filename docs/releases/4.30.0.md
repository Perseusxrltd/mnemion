# Mnemion 4.30.0

An encrypted server backup can now be opened from **Recover a workspace** in
the desktop app. Inspect its database, review the included access ledger or a
newer encrypted copy, and restore into a separate local workspace on Windows,
macOS or Linux.

The original organization and memory IDs survive. The selected deletions and
permissions are reconciled and fresh administrator access is issued. Recovery
requires explicit confirmation; a separate ledger cannot predate the one already
included in the package. The existing workspace and source backup are retained.

Server source runners, provider credentials, company sign-in, cloud models,
vault host keys and network/OS settings remain in the original encrypted package
for separate setup. The app explains this before recovery. This feature restores
the database; the existing supervised-host recovery workflow remains available
for reconstructing the server configuration.

The same private local-agent operations support inspection, reviewed recovery,
listing copies and switching to a verified result. Ordinary desktop snapshots
retain their existing workflow. No database schema migration or paid service is
introduced.
