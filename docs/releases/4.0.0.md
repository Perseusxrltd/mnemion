# Mnemion 4.0.0 — shared-memory platform v1

This is the first release of the rebuilt organization memory platform. The
distribution version advances to 4.0.0 because the previous product already
shipped 3.5.5; existing package managers must see an upgrade.

**Shipping status: release candidate under final validation.** Signed desktop
publication requires valid Windows publisher and Apple Developer ID/notarization
credentials. Native validation artifacts must not be promoted to the update feed.
See [the validation report](../validation/2026-10-10.md) for measured evidence.

The six native platform/architecture checks have passed for the documented
checkpoint. The project is maintained by **PERSEUS LEGACY LIMITED**. Trusted
signing and signed upgrade validation are still pending. Release work uses only
free services: no paid enrollment or trial that converts to a paid plan is
authorized. Free open-source signing is being evaluated; it is not yet approved.
Apple's standard paid Developer ID enrollment is not being pursued. See the
[code signing policy](../CODE_SIGNING.md) for the remaining distribution limits.

## Included

Mnemion is free forever, including all team features and updates. Optional
one-time PayPal support starts at €5, with higher amounts available. It does not
unlock or restrict anything; see [the support policy](../SUPPORT.md).

- Shared PostgreSQL memory with organizations, compartmentalized spaces,
  per-agent identities, scoped keys, immutable evidence/revisions and deletion.
- Durable ingestion and indexing, local multilingual embeddings, lexical and
  semantic recall, cited context and explicit queue/resource limits.
- Selectable small CPU and approved Ollama/OpenAI-compatible embedding profiles,
  scoped cloud approval, candidate reindexing, preview/evaluation and guarded
  activation/rollback. Recovery pauses endpoint processing for reapproval.
- HTTP/OpenAPI, Python/TypeScript SDKs and MCP stdio/HTTP for multiple assistants.
- Git, selected folders, Google Drive, Slack, rclone and custom source adapters.
- Studio for team administration, memory review, sources, wiki/graph, Obsidian,
  operations and detailed visual insights with private reproducible evaluations.
- Portable Obsidian Markdown, stable note paths, source anchors, conflict-aware
  refresh and preserved personal annotations/settings.
- Service backups and verified recovery, v3 preservation/import/cutover/rollback.
- Native desktop packaging with background mode, default login startup, stable
  automatic updates and safe idle restarts. Linux DEB and servers use managed
  deployment updates; AppImage supports the desktop updater.
- Offline in-app documentation, setup and security guides, full product roadmap
  and versioned release notes, bundled from the same Markdown as the repository.

Use the [deployment guide](../service/deployment.md) and
[Studio guide](../../studio/README.md). Existing v3 users should preserve a full
archive and rehearse recovery before migration; shared memory is an explicit
architecture change, not an unattended conversion of a personal vault.

## Scope and next patches

A configurable local/cloud librarian remains unfinished. Selectable embedding
providers and controlled reindexing are now implemented; larger model/hardware
comparisons and live-provider validation remain open. Current retrieval evaluation is
published with its small-sample and evidence-level limitations; large concurrent
capacity, answering accuracy and live customer-provider integrations are not
certified by the transaction fixtures. Vault exports are plaintext Markdown,
not an end-to-end encrypted search system. See the
[organization security model](../service/organizations.md).

The update policy and publisher setup are documented in
[Background operation and updates](../service/updates.md). Patch versions use
immutable artifacts and independent architecture feeds; incomplete or unsigned
desktop releases are not pushed automatically to installed clients.
