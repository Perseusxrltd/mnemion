# Mnemion 4.46.8

Scheduled snapshots and access-ledger backups can now wait for active source
scans to finish. New scans pause for up to five minutes while the capture
acquires its lock; existing scans continue naturally. Capture rechecks settings,
the active runtime and its output destination before starting.

The release also corrects the Windows test launcher and Linux compiler
compatibility problems that prevented 4.46.7 from being published. All release
checks remain in place. See [release status](../RELEASE_STATUS.md)
for current availability and the [validation report](../validation/2026-10-25-native-build-portability.md)
for evidence and limits. Product telemetry remains disabled and incomplete.
