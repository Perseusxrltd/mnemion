# Mnemion 4.46.13

[4.46.13 is published](https://github.com/Perseusxrltd/mnemion/releases/tag/v4.46.13)
as of **26 October 2026, 04:16:10 UTC**. It combines the unpublished
4.46.7–4.46.12 backup and privacy-control work with further Mac packaging and
native validation corrections. [All six installed targets and artifact
verification passed](../validation/2026-10-26-44613-native-acceptance.md).
Public automatic-update checks remained in progress at this checkpoint; see
automatic [release status](../RELEASE_STATUS.md) for evolving gates.

Managed snapshots and access-ledger captures wait up to five minutes to acquire
the host lock while active source scans finish. Before writing, capture refreshes
settings, rejects a runtime transition during the wait and rechecks destinations.
Local encrypted backups reuse their authenticated identity connection to estimate
disk requirements, retaining TLS, process, tenant and disk checks. The original
Windows connection timeout remains documented without an established cause.
See the [managed capture](../validation/2026-10-25-host-backup-capture.md) and
[local backup](../validation/2026-10-26-windows-backup-connection.md) evidence.

Mac installer builds give the same checksum-pinned vendor tool **twelve detach
attempts**, using its existing backoff. The affected managed-update test uses
fresh HTTP connections across listener replacements, retaining its request
limit and all readiness, backup, rollback and memory assertions without adding
request retries. The original Intel Mac busy-volume and connection-reset
failures remain preserved; the responsible process and TCP-reset cause are
unproven. The [Mac validation report](../validation/2026-10-26-macos-release-reliability.md)
records these changes and the local checks. The frozen 4.46.12 candidate remains
unpublished, with its failed results preserved separately from this release's
six-target installed qualification.

Windows installed-test protection now recognizes version-suffixed Mnemion Studio
installation names before running an installer. Earlier build-portability,
bounded helper cleanup, model/recovery diagnostics and native deadline-check
corrections from [4.46.12 and its preceding candidates](4.46.12.md) are retained.

Privacy controls show a fixed, clearly labeled four-byte report-format example
without changing consent, queued counts or sending allowances. App and native
agent controls use the same format; changing a choice or refreshing settings
clears the previous preview. This remains a synthetic example, not inspection
of the actual next outgoing packet. Native telemetry also requests SQLite
allocation cleanup before closing connections, without caching positive
permission or retaining an open connection. The
[cleanup and renderer evidence](../validation/2026-10-26-telemetry-sqlite-cleanup.md)
does not establish a causal memory improvement or full resource acceptance.

The optional collector source retains socket isolation and coarse closed-week
volume reporting, with detailed views requiring their existing larger sample
threshold. **Product telemetry remains Building and inactive**, with production
collection disabled and no destination or route selected. Exact-packet
inspection, production privacy/ingress, resource and full-platform acceptance
remain open. All 66 product requirements retain their scope and states.

Source validation includes wrapper/configuration syntax and pinned CLI argument
checks, one focused real managed-runtime test on Linux, and **44 Electron checks
with two Windows-only skips**. Three compiled Linux renderer journeys completed
**1,161 successful real fixture API requests** with verified cleanup. Earlier
backup and privacy-control checks remain linked from the cumulative notes.
These source checks preceded the six-target installed qualification. Publication
does not establish an actual user deployment: the last separately verified
[Windows/shared-host pair remains 4.46.6](../validation/2026-10-26-issue45-acceptance.md).
The later Linux/macOS CPU-sensor optimization is separate source work and is
not included in this release.
