# Mnemion 4.46.55

This release integrates the new product-telemetry report format across the
app, browser and Python clients. Collection remains unavailable: the saved
preference defaults to enabled, but there is no production destination or
release route. V08 remains Building.

Each report is a 25-byte bounded summary of 19 usage, reliability, performance
and resource metrics. Reports support comparisons by release or by coarse
operating system. Disabled categories and missing sensors retain distinct
labels. Memories, prompts, token text, keys and identifiers are excluded.
The collector can read a summary; noise protects the published weekly totals.
These totals describe reports, not unique people or exact event counts.

Saved opt-outs, company restrictions, delivery limits and manual review remain
in force. Valid stored approvals for the older four-byte format are invalidated
without being sent. Sending also checks that every category in the prepared
report remains permitted. See [privacy controls](../guides/product-telemetry-controls.md).

Maintainers can export private, self-contained HTML, CSV or JSON reports with
weekly trends, metric distributions and bounded percentile estimates. Release
preparation automatically maintains up to 32 comparison versions. Closed weeks
keep their original release lists. See the [v3 reference](../implementation/anonymous-product-telemetry-v3.md).

The [client evidence](../validation/2026-10-29-telemetry-v3-client-encoder.md),
[qualification probes](../validation/2026-10-29-telemetry-v3-probes.md) and
[phase-memory diagnostic](../validation/2026-10-29-telemetry-phase-memory.md)
record the source checks and their limits. Live collection, provider privacy
qualification and the installed resource gates remain unfinished. The normal
release and website automation records installer verification and automatic
update results in [release status](../RELEASE_STATUS.md).
