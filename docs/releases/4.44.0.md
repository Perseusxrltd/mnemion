# Mnemion 4.44.0

Security hotfix for the bundled Python dependencies:

- **Certifi 2026.10.19** excludes the affected emSign trust roots following
  intermediate CA key compromise (`PYSEC-2026-4320`). The service and desktop
  build both require the patched version.
- **Pillow 13.0.0** fixes all eight advisories reported against Pillow 12.3.0.
  The locked service runtime explicitly overrides FastEmbed's older Pillow ceiling.

FastEmbed 0.9.0, the text encoder, pinned weights and model-generation IDs remain
unchanged. One offline E5/BGE comparison produced identical 384-dimensional
query/document vectors, token counts and complete text spans, with maximum
absolute difference zero. This is bounded parity evidence for the tested fixture;
the hotfix introduces no model/index generation change. Capture and L1 feature
delivery remain separate.

Source installations use the [locked uv setup](../../README.md#run-the-service).
Ordinary `pip install` cannot resolve FastEmbed's `Pillow<13` constraint alongside
the patched Pillow requirement and does not apply the explicit uv override.

The [security validation](../validation/2026-10-21-security-dependencies.md)
records zero known vulnerabilities in audited dependencies, the auditor's skipped
local Mnemion package, and five successful service wheel target resolutions.
Native packaging, publication, public updates and actual installed acceptance
remain separate release gates; follow the [current roadmap](../ROADMAP.md)
and [release status](../RELEASE_STATUS.md) for their results.
