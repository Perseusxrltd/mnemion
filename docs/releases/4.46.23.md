# Mnemion 4.46.23

Automatic managed-server updates gain an explicit telemetry owner under the
server account's own acknowledged preference. Fresh staging, completed apply
and rollback have fixed outcomes. Cached stages, manual/library operations and
interrupted work add no inferred use; private update journals are never converted
into telemetry.

An existing or approved held report can be offered during the updater's normal
waits, with current privacy, network and spending checks. Delivery closes before
update work resumes. No extra periodic wakeup, worker thread or shutdown flush
is added. Both baseline and isolated updater entrypoints are covered.

This batch also includes the [native transaction metadata optimization](../validation/2026-10-26-telemetry-query-ownership.md):
fewer statement wrappers and query rows, with current authority checked inside
each transaction. It does not establish reduced RSS or CPU usage.

The generated coverage inventory exposes 88 mapped categories and six unmeasured
out of 94, and 628 actions/fixed variants. The app/browser and agent controls use
the same Git source. User and technical documentation describe the host policy
and the distinction between observed service readiness and desktop installer
handoff.

[Source validation](../validation/2026-10-26-telemetry-host-updates.md) passed
164 distinct Python cases, including real local TLS delivery/cancellation and
PostgreSQL API/worker recovery, plus frontend and Electron builds. Initial test
stub, stale-bundle and build-directory failures are preserved with their
corrections. A stale browser CI coverage-count assertion is also preserved and
corrected: browser and Python preview tests now compare the complete checked Git
inventory instead of duplicating its totals. The browser telemetry selection
passed 120 cases; the updated Python preview selection passed its 15 cases.
Native qualification and publication remain separate release gates.

destination/route. Resource, provider privacy, utility and installed-platform
acceptance remain open. All 66 requirement texts and the existing privacy and
resource limits are retained. See [release status](../RELEASE_STATUS.md) for
