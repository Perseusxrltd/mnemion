# Mnemion 4.46.56

Workspace sign-in now allows 60 seconds for password login and invitation
acceptance. A server can finish those operations after the previous 20-second
client deadline, leaving a valid session behind even though the app reports
an unconfirmed result. Other sign-in operations retain their existing deadlines.
No request is automatically replayed.

Sign-in and identity checks now distinguish known DNS, certificate, proxy,
timeout, connection and redirect failures with clear guidance. Unknown errors
remain unconfirmed. Messages exclude raw server errors, addresses, credentials
and exception details. See the [workspace qualification](../validation/2026-10-30-workspace-network-diagnostics.md).

Desktop and browser telemetry validation now avoids building encoded objects
and cell arrays that it immediately discards. Input validation, consent,
company controls and delivery limits are unchanged. The
[focused qualification](../validation/2026-10-30-telemetry-validation-allocation.md)
records the checks; no RAM or CPU saving is claimed from those tests.

Product telemetry is still unavailable in this release. Its 19 metrics and
private HTML/CSV/JSON reporting tools exist, but there is no production
collection destination or real fleet data to retrieve. Installed delivery,
resource limits and production collector qualification remain open under V08.
See the [telemetry status](../implementation/anonymous-product-telemetry-v3.md).

The [release status](../RELEASE_STATUS.md) automatically records downloads,
platform verification and public update results. All 66 product requirements
remain tracked with their existing states.
