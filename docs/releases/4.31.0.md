# Mnemion 4.31.0

Set up folder, Obsidian and growing JSONL conversation sources directly in
**Connections → Run on this computer**. Choose the folder, confirm its mapped
audience and save. Administrators can create a dedicated application key in the
same flow. A contributing device can use a shared workspace without running
its own database or model.

Source keys use OS-protected storage and owner-only native settings. Background
scans resume with Studio; users can pause, resume, change keys and limits, or
remove a device's source. **Sources on this computer** also works from the
welcome screen while signed out or when a workspace is offline.

One scan runs at a time, with fair ordering and coalesced manual requests.
Adjust the scan interval, file limit and source RAM allowance. The helper
reports resident memory, stops above its allowance and reconciles committed
progress on its next run. Partial inventories retain good data; conversation
capture reuses fragments and waits for complete records.

Five matching private local-agent operations cover status, configuration,
pause/resume, scan and removal. Existing update guards wait for source work,
pause scheduling during restart and resume it after a cancelled update. Generic
network memory access does not grant control over a device.

Existing Git, Drive, Slack, rclone and custom adapters remain available. Their
provider-specific graphical onboarding and full chat-history integrations remain
on the roadmap. No database migration or dependency is added.
