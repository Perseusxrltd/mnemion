# Mnemion 4.46.58

The shared librarian does less work while idle. Empty queue checks back off from
two seconds to a 30-second sleep cap. A newly committed run from the app or API
wakes the receiving service process, and repeated notifications coalesce.
Scheduled and cross-process work keeps a bounded fallback. Active processing
retains its pacing, permissions, resource checks and job budgets. See
[background operation](../service/librarian.md#background-operation).

Desktop telemetry admission now takes a fresh CPU sample after its existing
prepare wait. An early timer could previously leave the first sample cached
and refuse an otherwise eligible attempt. Ordinary reads stay cached and the
change adds no polling. The targeted Mac ARM diagnostic delivered both expected
fixture reports and completed all six workloads; the
[admission report](../validation/2026-10-30-telemetry-cpu-admission.md) records its
scope and measurement limits.

Fourteen focused librarian checks passed, including real PostgreSQL access,
cancellation and SDK checks. The
[idle-worker validation](../validation/2026-10-30-librarian-idle.md) records the
result. Whole-application CPU and RAM savings have not been measured by these
checks. The [runtime efficiency work](../implementation/runtime-efficiency.md)
continues across the product.

Production product telemetry remains unavailable while collector hosting and
resource acceptance are completed. This release does not enable fleet
collection. [Release status](../RELEASE_STATUS.md), downloads and website notes
are maintained by the existing release automation.
