# Mnemion 4.46.45

The separate telemetry collector can receive renewed TLS material through one
private, atomically replaced certificate/key bundle. Its service manager takes
one credential snapshot, preventing a renewal from mixing two generations.

The Linux rotation command validates the real pair, expected hostname and
remaining lifetime without a network connection. It refuses unsafe files and
concurrent rotation, preserves the installed pair on validation failure, and
can restart an already running collector. Unchanged material and unrelated
Certbot renewals do not restart it. A stopped collector stays stopped.

This prepares automatic certificate renewal; it does not enable collection or
qualify the public endpoint, certificate authority, provider privacy, client
resources or installed delivery. Full telemetry remains in progress.
