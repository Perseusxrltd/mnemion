# Mnemion 4.45.0

Retain selected conversation records on your device before they reach a shared
workspace. The encrypted inbox continues collecting approved local JSONL during
a network outage and keeps accepted records through app restarts or removal of
the original logs. Capture itself needs no model or paid service.

- **Choose and preview capture:** use Selected, Conversation or Detailed presets,
  session/file filters, JSON-field exclusions and an explicit audience review.
  Existing mirror connections keep their behavior; retention is an opt-in setup.
- **See what happened:** inspect observed and accepted prefixes, omitted records,
  genuine gaps, pending delivery and indexing separately in the app or through
  native agent controls. Unknown history remains unknown.
- **Recover safely:** export and inspect an encrypted inbox, restore it with new
  protected keys, or apply an administrator-reviewed policy replacement. Recovery
  preserves forgetting decisions and paused state; interrupted retirement can be
  reconciled without repeating an uncertain action.
- **Control resources and retention:** configure local intake, history and
  database limits without trimming accepted queues. Optional server expiry uses
  approved fragment-family deadlines and visible cleanup progress. Offline
  pending content, original files and backups retain separate lifecycles.
- **Run without Studio:** the packaged engine and service expose independent
  retained capture with private JSON configuration, local agent controls,
  background watching, recovery and reviewed policy changes.
- **Keep delivery reliable:** includes Windows policy-recovery and path fixes,
  the existing Codex/startup/native-crypto fixes, and corrected release reporting
  and version preparation. App guides, release notes and the website continue
  consuming Git sources; older documentation section links remain usable.

Both the app/runner and workspace need **4.45.0 or later** for retained capture.
Managed servers use the existing [reviewed upgrade](../service/managed-upgrades.md)
and verified backup for the five new capture migrations. Compatible hotfix
auto-updates retain their existing policy. Installing the app does not enroll a
source or enable a separately paused publisher.
