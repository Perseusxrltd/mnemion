# Mnemion 4.46.47

An all-space search now reports `scope_changed` when its readable spaces change
while it is running. Expired source permissions and newly readable spaces no
longer produce a misleading model-settings error. Search still checks current
access before inference and before returning results; actual model changes
retain their existing conflict response.

The [scope qualification](../validation/2026-10-29-search-scope-conflicts.md)
passed 41 PostgreSQL scope, reindex and retrieval checks. The concurrency and
latency incidents in issues #47 and #48 still require deployed-host acceptance.

The telemetry certificate guide now includes a completed
[Linux systemd rotation check](../validation/2026-10-28-telemetry-systemd-rotation.md):
changed credentials restart the service, unchanged credentials do not, and an
inactive collector stays inactive. This used synthetic certificates and a
temporary loopback listener. Production telemetry remains disabled while its
remaining privacy, resource, wire and installed-delivery checks are completed.

Release publication and native installation qualification are pending. All
installer compression, vault metadata controls and recovery fixes from
[4.46.46](4.46.46.md) are retained.
