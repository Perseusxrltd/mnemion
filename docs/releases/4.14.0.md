# Mnemion 4.14.0

Questions about a particular task can miss the relevant decision inside a long
log, while “recent” can put a newly edited but weakly related file first. This
release adds passage chronology and stronger question-term support to address
the concrete cases in issues 17 and 31.

- Plain hybrid questions containing IDs use surrounding key terms. Their
  contribution scales with query coverage, and the response exposes its factors.
- Unchanged passages retain their dates across file revisions. Dated sections
  and numbered decisions can be compared independently; a change elsewhere
  does not make an old status line new.
- Recent ordering prioritizes comparable matches before their dates. The app
  and API expose a 0–100% threshold; zero gives strict chronological ordering.
- Search explains the selected passage date and its source. Calendar dates
  without timezone-qualified times are shown at day precision.
- Evaluations can compare recent, strict-date and relevance runs, retaining
  their settings, retrieval implementation and execution-version evidence.
- Python clients omit the new nested setting and evaluation order unless the
  caller requests them; the app enables new controls only on compatible servers.

Migration **021** adds private revision chronology with an empty historical
default. It requires no new dependency, model download or re-embedding. The
installed-upgrade gate accounts for that exact empty default while still
detecting changed chronology, memory data or access state.

See [search and chronology](../service/retrieval.md) for the bounded candidate
and passage limits. Source dates do not prove truth or supersession. Historical
Git blame, ambiguous/undated history and broader live model evaluations remain
open; these changes do not close the entire natural-language-quality scope.

The [validation record](../validation/2026-10-19-passage-chronology.md) separates
source checks from the six platform release, publication and public-update
gates. Published downloads are tracked in [release status](../RELEASE_STATUS.md).
