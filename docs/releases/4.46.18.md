# Mnemion 4.46.18

The privacy page now distinguishes telemetry categories with declared
measurement sources from categories that remain unmeasured. Filter the
inventory by feature family or coverage, in the app or browser. Native agents
receive the same inventory through the existing offline `schema` and `preview`
controls. The inventory loads only when requested and is generated from the
reviewed source maps; release checks reject stale coverage.

The telemetry documentation now separates the current contract from its dated
evidence index. A pinned private SQLite experiment was rejected after its fixed
measurements showed no convincing resource benefit. No database backend,
resource budget or privacy permission changed. Product collection remains
unavailable while full V08 acceptance continues.

Validation and limitations are recorded in the [coverage report](../validation/2026-10-26-telemetry-coverage.md)
and [allocator decision](../validation/2026-10-26-telemetry-private-sqlite.md).
Native installers, publication and automatic updates retain their normal
release gates; source implementation does not establish public availability.
