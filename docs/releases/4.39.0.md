# Mnemion 4.39.0

Connect more native agents, give busy-host administrators a bounded maintenance
turn, and keep a free weekly watch of relevant memory research. This release
carries the connector work from the unpublished 4.38 candidate and fixes the
missing branding input found by its container gates.

- **Hermes and OpenClaw setup:** Studio and agent controls install their native
  YAML/JSON5 profiles with private credentials, exact backups, observed status
  and safe removal. Duplicate keys fail before replacement; YAML aliases cannot
  accidentally change unrelated settings. Existing Codex, Claude and Grok Build
  setup remains supported.
- **Perseus XR connection packages:** download a provider-specific package from
  the app or generate it through the authenticated API, SDKs and standalone CLI.
  Packages contain the HTTPS MCP address, canonical logo and instructions without
  embedded credentials. Grok Bot receives an accurately labeled connection guide;
  supported plugin targets receive manifests and Hermes/OpenClaw receive native
  configuration. Actual provider sign-in and catalog approval remain separate.
- **Busy-host upgrade fix:** managed `updates plan` and `updates upgrade` wait up
  to 60 seconds for their operation lock, adjustable with `--wait-for-turn 0–300`.
  Existing source scans finish while new ones briefly defer. Failed operations
  are never replayed by this wait, and a crashed operator cannot leave an
  indefinite source pause. This addresses the contention observed in issue 45;
  its private live-upgrade acceptance remains separately tracked.
- **Container packaging fix:** the frontend image includes the canonical package
  logo before branding validation. Both container architectures in candidate
  4.38 correctly withheld publication when that input was absent.
- **Research and documentation:** the expanded layered-librarian study preserves
  raw capture, consolidation, evidence, statistics, autonomy and visual controls
  as seven delivery stages. A weekly free metadata watch records papers and
  memory-tool/model changes, including feed failures, without model calls or
  dependency upgrades. Jev remains an optional disabled paid-provider candidate;
  the free local librarian path remains required.

There is no new database migration after 4.37. Earlier hosts that still need
migration 029 use the documented guarded upgrade. Current keys and grants retain
their authority. Real Grok Bot cloud acceptance and deployment issues 44/45/46
remain open until their own evidence passes; a healthy API does not prove fresh
capture from an intentionally paused PC publisher.
