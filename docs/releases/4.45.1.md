# Mnemion 4.45.1

This hotfix strengthens provider imports, recovery and private diagnostics,
and adds an optional browser policy for company-hosted workspaces.

- Provider requests share a 60-second budget across retries and streamed reads,
  including company proxies. Oversized chunks are rejected before copying;
  compressed responses are not expanded implicitly.
- Backup and restore tools receive their platform and PostgreSQL connection
  settings without inheriting unrelated application, model or vault credentials.
  Supported TLS, authentication and passfile settings remain available.
- HTTP, MCP and connector errors keep useful schema field names while hiding
  arbitrary submitted property names and limiting diagnostic size.
- Spreadsheet imports apply the same restricted XML policy across supported
  text encodings. Ordinary Unicode text and formula-as-text behavior remain.
- Company operators can restrict hosted Studio to its own origin and explicit
  additional workspace or local bridge origins. The default multi-workspace
  policy remains compatible with existing installations.
- Secret scans run automatically before normal source integration, in CI and
  release preparation, on generated desktop content, and on downloaded release
  distributions before publication. Binary and nested-wheel rejection controls
  check the scanner itself. All tools and this pipeline remain free.

This release also includes the development-preview help-link correction already
on main. It adds no database migration. The 4.45 capture controls, existing
Obsidian workflow and separately paused publishers retain their established
behavior. Both installed-native and actual-deployment acceptance are recorded
separately from source checks.
