# Mnemion 4.0.7

Linux and macOS hosts without systemd can now keep the API and worker in the
background using a private Supervisor instance. This addresses issue 6 with a
maintained process manager, explicit startup configuration and JSON lifecycle
commands for operators and maintenance agents.

## Changes

- Add the free `supervision` extra, pinned to Supervisor 4.3.0 on Unix systems.
  `mnemion-service supervise` can prepare, start, inspect and stop both processes,
  or run in the foreground under an existing init system.
- Generate private role-specific credential files, a local-only control socket,
  rotated process logs, a quoted Linux cron entry and a macOS launchd plist.
  Preparation preserves existing configuration and does not register host startup.
- Restart unexpected API and worker exits. Readiness checks both process states
  and the exact API instance/PID; an unrelated healthy listener cannot count as
  a successful start. Stop waits through Supervisor's shutdown state.
- Keep administrative database credentials and owner API keys out of the child
  environment. Modified configuration and exposed managed files fail explicitly;
  common third-party errors do not print rejected private inputs to JSON output.
- Generate offline API/agent schemas independently of web assets. A stale local
  Studio build after a source-version change no longer prevents schema export;
  normal server startup still validates the selected bundle.
- Add real process-recovery checks to Linux service CI and dedicated native
  macOS ARM64/Intel jobs. Keep all six desktop release targets and their update
  feeds in this patch.
- Fix Intel Mac server installation by selecting ONNX Runtime 1.23.2 on Python
  3.12/3.13, the newest compatible upstream wheels. Other platforms retain the
  newer runtime; models, generations and stored vectors remain unchanged. Native
  Mac CI now tests both real local models and audits its installed dependencies.
- Retry transient downloads of the pinned Mac updater build dependency. Only
  complete, hash-verified bytes are published; integrity/size failures and
  existing output files cannot be overwritten or retried as network errors.
- Record the preceding public 4.0.5 → 4.0.6 automatic upgrades on all six targets,
  preserving profiles with production feeds and normal idle/restart guards.

## Upgrade and configuration

There is no new database migration, embedding generation or reindex requirement.
Use the [background-service guide](../service/supervision.md) after installing the
matching package/extra and provisioning PostgreSQL. An official Python archive
includes Studio; a Git checkout needs `mnemion-service studio build` before
restarting the updated API. A server older than 4.0.5 still needs that patch's
coordinated migration and rollback procedure.

The supervisor manages the API and worker, including the API's combined MCP/UI.
PostgreSQL, source runners and tunnels keep their own lifecycle. Windows retains
the [Compose service deployment](../service/deployment.md); Supervisor is a Unix
dependency. Desktop updates do not install or upgrade an organization server.

This process manager provides restarts, not verified software auto-updates or
memory/CPU isolation. Repeated early startup failures enter `FATAL` after the
documented retries. Host boot configuration, operating-system limits and the
database/network startup order remain operator responsibilities.

## Validation and remaining work

Tests run a real API, worker, restricted database logins and PostgreSQL. They
force worker and API crashes, observe replacement processes, preserve the
authenticated identity and verify graceful, repeatable shutdown. Additional
checks reject wrong-instance/old-process health responses, credential exposure,
configuration changes, unsafe paths and private error disclosure. Model calls
are not part of this lifecycle test. Full product and native release gates remain
mandatory before publication; results are recorded in the
[dated validation report](../validation/2026-10-11-hotfixes.md).
The final local service suite passed 261 tests with two opt-in model skips and
86.40% coverage; the focused lifecycle/web group passed 16 tests. The installed
candidate wheel's guide passed desktop/mobile browser checks without console
errors. These local results do not substitute for the native release gates.

Verified server software updates with backups and safe rollback (issue 11),
hosted-agent OAuth, remote-access setup, further memory reductions and retrieval
evaluations remain on the [roadmap](../ROADMAP.md). Publisher-signing limitations
and the requirement for deployment-specific boot/managed-device tests remain.

native release gates passed. Both native Mac jobs additionally passed their
supervision, real E5/BGE inference and installed-dependency checks. The Intel
runtime compatibility fix was included in this successful replacement run.
