# Mnemion 4.46.63

Managed hosts recover sooner from temporary connectivity failures while
checking for updates. The existing watcher schedules at most two earlier
attempts, roughly five and fifteen minutes apart with jitter, capped by the
configured check interval. The saved allowance survives restarts and a busy
operation lock; ordinary idle checks keep their existing cadence.

Successful checks and nontransient check failures end the retry episode.
Certificate, integrity, HTTP, local-storage and stage/apply failures keep the
ordinary schedule. New transport diagnostics use fixed categories without
retaining exception text, addresses, headers or credentials. Signed-release,
version, migration, backup and recovery gates remain enforced; an
operator-required result waits for the authorized host operator.

The [focused updater verification](../validation/2026-11-01-managed-update-retries.md)
passed all 165 cases, including persisted retries, compatible signed updates,
schema refusal and private error reporting. Actual published installers and
automatic-update results are tracked in [release status](../RELEASE_STATUS.md).

Developer diagnostics also now have a verified [Windows declaration comparison](../validation/2026-10-31-windows-sdk-abi.md):
14 structure sizes and 137 addressable fields matched the native SDK on x64
and ARM64. ETW tracing and application resource-budget acceptance remain open.

The [full professional product goal](../PRODUCT_GOAL.md) and all 66 requirements
remain in scope. F06/R04 remains Partial; V08 remains Building and production
telemetry stays off. This release adds no new background worker or model load.
