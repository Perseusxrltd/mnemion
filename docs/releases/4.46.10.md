# Mnemion 4.46.10

This candidate retains the fixes from the unpublished 4.46.7–4.46.9 candidates:
[managed backup captures](../validation/2026-10-25-host-backup-capture.md) wait
up to five minutes to acquire their lock, refresh settings and reject a runtime
transition before writing; native build portability, bounded Windows test-helper
cleanup and [collector socket isolation](../implementation/anonymous-product-telemetry-collector.md)
are preserved.

The [native deadline check](../validation/2026-10-25-native-telemetry-deadline.md)
now measures the peer's actual TCP close against the existing five-second
reservation deadline while deliberately delaying cleanup completion. Its timing
allowance is unchanged. This corrects validation; production transport code is
unchanged. The original 4.46.9 failure remains documented.

Collector [report schema v2](../validation/2026-10-25-telemetry-weekly-volume.md)
adds a coarse closed-week volume bucket after 64 accepted contributions, while
detailed views still need 4,096 reports each. Existing immutable v1 reports remain
readable; the four-byte wire format and client budgets are unchanged. The focused
reporting selection passed 67 tests.

Product telemetry remains disabled and incomplete, with no production destination
or route selected; V08 remains Building. Native release, publication and installed
acceptance are pending. See automatic [release status](../RELEASE_STATUS.md)
for current availability.
