# Mnemion 4.41.0

Choose how much an approved live conversation source sends to memory, through
the app or the same native agent controls.

- **Capture choice:** keep complete exposed session records and readable messages,
  or copy supported user/assistant messages only. Message-only mode excludes raw
  records and structured tool, system/developer and reasoning content according
  to the supported format. Ordinary message text is preserved verbatim.
- **Visible capture scope:** source progress reports the chosen mode. Its byte
  count distinguishes a source prefix examined for messages from a stored raw
  archive. Projections retain generation, hash and byte/line provenance without
  claiming that an omitted raw record is stored in Mnemion.
- **Safe mode changes:** complete source reconciliation re-examines cached
  references. Existing permission checks, partial-record handling, bounded
  resources, human corrections and deletion protections remain effective.
  Earlier archives and backups follow their normal retention rules.
- **Complete-milestone planning:** the acceptance audit preserves all 65
  requirements and decomposes the 42 partial requirements into remaining work,
  dependencies and required evidence. Work proceeds through complete user/agent
  journeys alongside urgent repairs, with no scope removed or invented estimates.

The existing `complete` capture mode remains the default for enrolled sources.
Message-only capture requires conversation normalization. Providers decide which
events they expose; this cannot obtain hidden reasoning or unknown provider
histories. These controls are a foundation for the broader layered librarian,
not autonomous consolidation or verified model conclusions.

No new database migration or paid model is required. The native source runner
needs 4.41; existing compatible workspace services receive the normal source
inventory and checkpoint. Earlier clients retain their normal capture behavior.
