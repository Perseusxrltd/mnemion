# Mnemion 4.23.0

This candidate was **withheld**: Intel Mac managed-install checks found that
the selected Argon2 bindings had no compatible binary wheel. Version
[4.24.0](4.24.0.md) carries this KeePass work with the corrected platform pin.

KeePass users can preview and import a KDBX 4 file directly from **Secrets →
Import KeePass**, then export selected credentials back to a password-protected
KDBX 4.1 file. Standard fields, custom properties and entry CustomData map to
individual credentials. Masked account/group/custom-field names are the default;
original grouping and field names remain encrypted for later export.

An administrator reviews an exact preview before the whole import commits.
Repeating the same unchanged import does not create duplicates. Existing or
edited credentials are never overwritten. Only the importing person or key has
initial access; exporting requires an explicit read grant on every selected
credential. Selecting a password alone does not reveal the unselected title or
username. Values and grouping stay out of memory search, source sync and audit
payloads. Conversion creates no plaintext temporary files.

The same operations are available through the typed Python/TypeScript clients
and the agent CLI's private input/result files. Ordinary chat tool responses do
not carry credential transport files or passwords.

This release supports AES-256/ChaCha20 KDBX 4.0/4.1, AES-KDF/Argon2d/Argon2id,
Salsa20/ChaCha20 protected strings and standard XML/binary key files. Transfers
are bounded to 1 MB encrypted, 2 MB unpacked, 100 current KeePass entries and
500 nonempty credential fields. Export selects up to 100 credentials at once.
Import deliberately omits history, attachments and recycled/deleted entries;
the preview shows these counts before approval. It is a current-credential
transfer, not a complete KeePass database backup. See the
[KeePass guide](../service/keepass.md) for supported KDF costs and other limits.

Migration `026_keepass_portability.sql` adds nullable encrypted mapping columns.
Existing credential values and grants are preserved. Full host backups preserve
the mapping; deletion and recovery ledgers purge it alongside deleted values.
Portable Mnemion exports with KeePass mappings require 4.23 or later to import;
ordinary credential exports retain the previous format.

Availability is controlled by the release pipeline. A source version or this
document does not establish that native packages have been verified/published.
The live download page and release-status feed track that independently.

[Validation evidence](../validation/2026-10-19-keepass.md) records independent
KDBX readers, the real app download, permission checks and migration preflight.
