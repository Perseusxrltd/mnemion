# Mnemion 4.46.49

Search does less database work when ranking the age of relevant passages. It
now checks the already-selected candidates before building their chronology,
while preserving current permissions, source visibility and historical revision
rules. A real PostgreSQL regression reduced this step from **33 materialized
rows to one** for a single selected memory; the complete index count remains 33.

The [focused qualification](../validation/2026-10-29-selected-passage-candidates.md)
passed **61 checks** covering passage chronology, ranking, retrieval, historical
corrections, deletion and changing source access. Live latency acceptance and
the reported issues remain open until the corresponding field checks pass.

Documentation records the latest default hybrid searches, activity pagination
and independently verified backup delivery, including the separate cleanup
timeout. Full telemetry acceptance remains open and production collection is
disabled. Source CI, native qualification and publication for this version are
pending.
