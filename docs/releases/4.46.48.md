# Mnemion 4.46.48

Agents and Python/TypeScript clients now receive a retry hint when an all-space
search's permitted spaces change. They can make a fresh search with current
access. This corrects the `retryable: false` hint on `scope_changed` introduced
with the distinct conflict in [4.46.47](4.46.47.md). Requests are not replayed
automatically, and unprotected writes retain their retry restrictions.

The [qualification](../validation/2026-10-29-scope-retry-hints.md) passed
46 Python/MCP checks and 23 TypeScript checks, including an actual PostgreSQL
scope change followed by a successful fresh MCP search.

The installer verifier now rejects downloads over **400 MiB**. Balanced
compression and all packaged capabilities are retained; the normal six-platform
native checks must still pass. The [footprint record](../implementation/installer-footprint.md)
keeps download sizes separate from installed size and the reported 1 GB file.

Documentation adds the [four-client live search baseline](../validation/2026-10-29-mcp-field-sessions.md)
and the [isolated systemd telemetry crash/restart qualification](../validation/2026-10-29-telemetry-systemd-crash.md).
The live latency incidents and full telemetry acceptance remain open.
Production telemetry is still disabled. Publication and native installation
qualification for this source are pending.
