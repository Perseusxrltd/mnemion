# Mnemion 4.36.0

## See what is waiting in the memory pipeline

**Insights → Sources & pipeline** now separates indexing from physical cleanup,
with pending, leased and failed counts, due jobs, retries and oldest age. It shows
the total saved text waiting for indexing and the largest input, making a large
import easier to distinguish from a purge backlog.

The same numeric `queue_work` groups are available through the existing scoped
API, SDKs, agent operations and JSON exports. Current reviewer authorization,
bounded collection and older-server fallback are retained. Counts describe the
selected space and their displayed snapshot time; text sizes do not predict
model latency, bandwidth or RAM, and due work still needs an available worker
and approved model.

[Database and browser validation](../validation/2026-10-20-queue-visibility.md)
passed, including narrow-screen layout and missing-field fallback. This release
adds no dependency or migration after 4.35's schema 029. Servers upgrading from
an earlier schema still need the [guarded upgrade](../service/managed-upgrades.md).
See [release status](../RELEASE_STATUS.md) for published installers and native
acceptance.
