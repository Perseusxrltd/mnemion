# Mnemion 4.22.0

Existing native memories can now join an approved Git journal through a separate,
resumable backfill. Enabling a journal still captures only future changes until
an administrator explicitly approves older content.

- **Git journal → Include existing memories** previews candidate counts and
  content size. Start, pause, resume or cancel scanning from the app, Python and
  TypeScript SDKs, or three named agent operations.
- A persisted cursor and bounded batches survive process restarts. Current
  revisions, native memory IDs, original authors and revision dates are retained;
  existing memories are not rewritten or re-embedded.
- Privacy checks run before capture. Rejected records remain unchanged and get
  bounded, content-free diagnostics. Deleted/quarantined memories are excluded;
  a later deletion suppresses pending text and publishes its normal denial.
- Current publisher access, administrator approval and destination policy are
  rechecked. Another authorized administrator can resume the existing job after
  its original approver loses access. Policy changes require fresh approval.
- Scan completion means capture finished, not that Git acknowledged every event.
  Queued events use the existing verified publisher. Full restore retains the
  cursor but pauses publication until the recovered host is reviewed.

This release also carries the [source-file isolation and health fix](4.21.0.md)
for issue 43. The frozen 4.21 candidate was withheld when upgrade tests retained
an outdated final-migration list. Those tests now apply every shipped migration
and verify that existing logins and journal policies survive.
Release preparation also checks old-schema upgrades before reserving native
builders, caching unchanged successful inputs. Its inventory includes the new
backfill table while retaining exact checks of existing data and permissions.

Migration 025 adds the resumable job, indexes and narrowly scoped approval and
scheduling functions. It changes no existing memory content or embedding.
Existing journal formats and destination fingerprints remain compatible.
