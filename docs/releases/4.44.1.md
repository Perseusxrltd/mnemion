# Mnemion 4.44.1

Quitting Studio during source startup waits for the outstanding settings read
to finish and keeps source scanning stopped. Startup cannot recreate its polling
timer after shutdown has begun.

The bundled native runtime initializes without requiring OpenSSL's unused legacy
provider. AES-GCM encryption, Ed25519 and RSA signatures, and Argon2id password
hashing and verification remain supported.

This patch follows **4.44.0** and contains these two corrections. L1 retained
conversation capture remains separate development work. The
[validation record](../validation/2026-10-21-desktop-startup.md) records the passing
source lifecycle and crypto checks. [Release status](../RELEASE_STATUS.md) tracks
installer validation, update checks and public availability automatically.
