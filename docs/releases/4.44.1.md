# Mnemion 4.44.1

Quitting Studio during source startup waits for the outstanding settings read
to finish and keeps source scanning stopped. Startup cannot recreate its polling
timer after shutdown has begun.

The bundled native runtime initializes without requiring OpenSSL's unused legacy
provider. AES-GCM encryption, Ed25519 and RSA signatures, and Argon2id password
hashing and verification remain supported.

On Windows, saving backup settings or remembered workspace connections retries
temporary file-sharing locks. Replacement remains atomic; the existing file
stays intact until its complete replacement succeeds.

This is an **unreleased candidate** following **4.44.0**. The first candidate
failed Windows installed validation. The revised candidate's TypeScript build
and focused Windows and Linux source checks passed, including the real Windows
sharing-handle regression. Installed acceptance remains pending.
L1 retained conversation capture remains separate development work. The
[validation record](../validation/2026-10-21-desktop-startup.md) preserves the
first candidate's results and tracks the correction. [Release status](../RELEASE_STATUS.md)
tracks installer validation, update checks and public availability automatically.
