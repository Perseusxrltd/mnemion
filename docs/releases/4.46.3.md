# Mnemion 4.46.3

**23 October 2026 source checkpoint: UNRELEASED.** This candidate adds explicit
independent-backup controls and corrects controller shutdown observation.
Current public packages and gates remain recorded in
[release status](../RELEASE_STATUS.md).

Operators and custodians can create encrypted memory packages with access/deletion
ledgers and verify retained copies through **Independent backups** in Host controls
or the matching native-agent actions, `backup.create` and `backup.verify`. The card
offers confirmation, creation, retained-copy details and fresh verification.
Both actions require explicit `approve_backup_transfer: true` and the current
`configuration_sha256`; verification additionally names a retained `backup_id`.
Older hosts advertise neither action.

After bounded source drain, the worker rechecks authority, approval expiry and
the configuration before using the host owner's existing Git storage. These
operations preserve the service's current intent and do not start, stop or
upgrade it. Lost replies retain the original operation UUID. Fresh verification
can proceed during an existing recovery once active work ends, without resolving
or replaying the older operation.

Host status exposes a bounded retained-copy inventory: sizes, recovery key IDs,
memory/ledger capture and readback times, file digests and the service version
when recorded. Private destinations, paths and credentials stay on the host.
Remote requests cannot choose arbitrary destinations, keys or commands. See the
[backup guide and agent examples](../guides/company-host-control.md#create-and-verify-retained-backups).
Readback verifies stored bytes; controller-authority escrow, replacement-host
takeover and successful restore remain separate, unaccepted capabilities.

The shutdown correction handles a Supervisor socket closing after
`lifecycle.stop` has requested independent controller shutdown. Only the
post-request observation tolerates `ConnectionResetError`, `BrokenPipeError`
and `RemoteDisconnected`. The **20-second bound**, **one shutdown request**
and **observed controller absence** requirement remain; identity and permission
errors still propagate.
