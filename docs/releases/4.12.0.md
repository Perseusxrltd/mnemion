# Mnemion 4.12.0

Add a separate **Secrets** vault for credentials shared with specific people
and agent keys. Set it up from **Setup & this device**, save an independent host
recovery key, then manage credentials and permissions in desktop or web Studio.

- Values use authenticated encryption and stay outside memory search, embeddings,
  automatic context, the librarian and Obsidian exports. Names remain visible
  metadata. Explicit reads clear from the screen after a minute or loss of focus.
- Grant list, read and write separately. Audit access without recording values.
  Export selected credentials as encrypted files and restore them with new IDs
  and fresh grants. Enable the MCP credential tools separately when required.
- Database recovery preserves later credential deletions and clears historical
  vault grants. Restore the separately saved host key and review access again.
- Ten HTTP/agent operations and two private desktop operations provide the same
  controls for automation. Private key reads require a result file, and bounded
  private vault files support the full portable-export size.

This adds migration **020**. Desktop-owned workspaces migrate through the existing
update/startup process. Independently hosted services use the supported operator
upgrade procedure; an older schema cannot acquire the feature from a desktop
update alone. No new paid service or model dependency is introduced.

The [vault guide](../service/secrets-vault.md) explains key custody, server-side
encryption, permissions and recovery limits. [Validation](../validation/2026-10-15-secrets-vault.md)
records focused tests and the source-app walkthrough. The existing six-target
installed backup/recovery gate now also requires vault setup, independent key
restoration, fresh grants, preserved deletions and restart persistence.
The [retention form readiness correction](../validation/2026-10-19-retention-gate.md)
keeps those assertions while waiting for the intended editable setup controls.

Managed key rotation, external KMS, optional KeePass interoperability, independent
cloud delivery verification and broader company policies remain on the
[roadmap](../ROADMAP.md). [Release status](../RELEASE_STATUS.md) and the
[product page](https://www.perseusxr.com/mnemion) identify verified published builds;
source preparation can precede installers.
