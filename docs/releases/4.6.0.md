# Mnemion 4.6.0

This release carries the guided encrypted backup/recovery workflow from the
unpublished 4.5.0 candidate, with corrected Windows folder ownership and file
timestamp handling. Windows encryption now compares compatible path/handle
metadata and keeps the full handle checks during reads. Encrypted-file
authentication and protection against changed inputs remain in place.

Trusted agents on your computer can manage Mnemion Studio through **Setup & this
device → Agents on this computer → Copy local agent setup**. The copied JSON
provides the installed command and discovery instructions without credentials.
The same panel is available during local setup.

The private desktop interface includes 19 actions for setup, start/stop, RAM,
local addresses, remote access, protected backup schedules, snapshot/ledger
capture, inspection, independent restoration and selection of recovery copies.
Commands confirm the current workspace identity and use the same bounded
controllers as the app. A local agent can operate while the app is in the
background or the Windows screen is locked, provided the app is running.

Workspace changes preserve unsaved edits: finish or discard them before an
agent switches the displayed workspace. Accepted switches show progress and
reconnect the app. Backup and restore operations support cancellation; automatic
updates wait for local mutations to finish. Request IDs prevent duplicate work
within the documented bounded session cache.

The interface uses an authenticated local OS pipe under the app owner's account.
Remote memory API/MCP keys and organization logins retain their existing scope.
Saved backup keys are never returned; newly generated keys require a private
result file. No HTTP control endpoint, model dependency or paid service is added.

The [operator guide](../service/desktop-operator.md) covers commands, inputs,
authority, error recovery, timeout and replay limits. The
[validation record](../validation/2026-10-15-desktop-operator.md) records 154
desktop checks and actual source-app/CLI schedule, restore and selection
walkthroughs. Installed acceptance extends those workflows across all six
targets; consult [release status](../RELEASE_STATUS.md) for actual availability.
The [Windows encryption regression](../validation/2026-10-15-windows-backup-metadata.md)
also reproduces the original failure and verifies the correction on Windows.

No service schema migration or memory re-index is introduced. Company host
delegation, powered-off-host recovery, verified cloud backup delivery, retention
and provider-specific workflows remain on the roadmap. Mnemion remains free.
