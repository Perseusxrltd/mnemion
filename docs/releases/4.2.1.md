# Mnemion 4.2.1

Status: **in development, not yet published**. The 4.2.0 candidate remains in
its separate release validation; use [current release status](../RELEASE_STATUS.md)
for available downloads.

This patch reduces memory retained after local embedding models unload on
Linux hosts using glibc. Cleanup also returns free allocator pages after an
eviction caused by the RAM budget. The normal idle delay, active-work guards,
stored memories and model fingerprints are preserved. Other operating systems
and allocators retain their existing cleanup behavior.

Isolated offline measurements reduced idle RSS from 432.0 to 107.0 MiB for
multilingual E5 small and from 144.9 to 106.2 MiB for English BGE small. Both
models reloaded with the same vectors and source spans. These measurements do
not claim a whole-host minimum or eliminate peak API/worker model duplication.
See [validation and limits](../validation/2026-10-13-idle-heap-reclaim.md).

This patch adds no database migration beyond 4.2.0. Hosts still on 4.1.x need
the controlled 4.2.0 schema upgrade before compatible automatic service patches
can apply. Desktop clients and independently hosted workspaces retain separate
update ownership. Full product checks, native packages, signatures and public
upgrades remain required before publication.
