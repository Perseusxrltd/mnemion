# Mnemion 4.46.43

This release improves large-workspace search and agent inventories, makes older
activity reachable, and explains the difference between space and organization
administration. It addresses parts of the
[multi-agent field reports](../implementation/multi-agent-field-readiness.md);
their remaining criteria stay open.

- Memory and audit queries reuse current authorization within each SQL statement.
  Grant revocation, tenant boundaries, source leases and capture custody remain
  enforced. A synthetic 800-memory query completed in about 280 ms after the
  original policy path timed out at 15 seconds; live latency still needs confirmation.
- `memories.list` accepts `summary=true` for bounded inventories without content,
  evidence or arbitrary metadata. The compact MCP tool accepts an explicit
  `max_response_bytes` up to 131072 while retaining its smaller default.
- Activity has opaque cursor pages and an exact action filter in the API, SDK,
  MCP and Studio. Empty journal filing passes update status without adding new
  `journal.organized` events. Existing audit history remains intact.
- Tenant-wide operation errors now name the required tenant-administrator role.
  A space administrator's permissions remain unchanged.

The [qualification record](../validation/2026-10-28-field-reliability.md) preserves
the initial MCP test failure, successful targeted correction, existing policy
checks and both synthetic query results. Studio and SDK production builds and
22 SDK tests passed locally. Migration 035 requires the normal
managed database-upgrade procedure; no live policy is patched ad hoc.
The original 66 requirements remain, with the new task/handoff and vault-format
acceptance explicitly retained in the field plan.

Product telemetry remains **Building**, with production collection disabled,
destination/route null and release authorities empty. Resource, wire,
provider/privacy and full platform acceptance are still required before its
completion notification. See [release status](../RELEASE_STATUS.md) for public
availability and installed-update checks.
