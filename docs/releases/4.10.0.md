# Mnemion 4.10.0

People can authorize assistants with their existing company account. When a host
enables Mnemion's OAuth consent flow and configures a company provider, the
connection page offers company sign-in alongside personal workspace login.
An approved workspace member completes provider authentication, reviews the
requesting app and their current permissions, and explicitly allows or cancels
the connection. Creating a separate Mnemion password is optional.

Company assistant connections follow the company's configured session lifetime:
eight hours by default, with an absolute expiry shown on the permission page.
Refreshing credentials never extends that deadline. Administrators can revoke
an individual app, a company identity link or a person's workspace access.
The company flow preserves remembered Studio logins and does not store provider
credentials in browser storage or expose them to the assistant.

Login handoffs are bound to the requesting browser, workspace and consent
request. Approval and code exchange recheck the reviewed permissions and current
company link. Revocation, provider-policy removal, expiry and credential replay
are enforced through the existing session and authorization controls. Personal
password login, application keys and independent recovery access remain available.

Migration `019_company_agent_consent.sql` preserves existing personal device
sessions, assistant connections and pending personal approvals. Separately
hosted servers require the [guarded operator upgrade](../service/managed-upgrades.md).
Desktop updates use the normal native migration and recovery gates.

The [account consent guide](../service/hosted-agent-sign-in.md) covers setup,
permissions and lifetimes. [Validation](../validation/2026-10-15-company-agent-consent.md)
records PostgreSQL checks, upgrade/recovery, an actual Dex/browser flow and
MCP SDK discovery, registration, PKCE, search, refresh and revocation.

This does not complete live acceptance in every named assistant product.
Provider-specific setup, automatic provisioning, group mapping, company-only
admission, back-channel logout and guided remote provider configuration remain
on the roadmap. Company-provider account removal alone does not instantly end a
Mnemion connection; local link/person revocation enforces immediate removal.

[Release status](../RELEASE_STATUS.md) tracks native packages, publication,
the live website and public automatic updates. This advances F08, C09 and
A03/A08; the full-scope [requirements](../PRODUCT_REQUIREMENTS.md) remain
**17 of 64 completely shipped (26.6%)**.
