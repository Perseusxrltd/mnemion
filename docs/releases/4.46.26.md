# Mnemion 4.46.26

Generated-content secret-scanner initialization gains one narrowly classified
download retry and fixed safe failure stages/codes. Pinned digests, size limits,
private-cache checks and all six canaries remain mandatory. Digest/TLS failures,
unrecognized errors and findings cannot trigger this retry; any unsuccessful
scan still blocks publication. Download deadlines are checked around chunks and
between attempts, with configured I/O timeouts capped at 30 seconds, without a
strict total wall-clock or DNS guarantee.

[Scanner source validation](../validation/2026-10-26-linux-package-recovery.md)
passed 37 focused tests and a real fresh acquisition of pinned Gitleaks 8.30.1.
All six canaries passed; 625 generated frontend/Electron files had zero findings
on local WSL/Linux x64. The original 4.46.24 hosted Linux initialization failures
remain retained and undiagnosed. These local checks do not establish the next
native release's success.

The [fixed resource follow-up](../validation/2026-10-26-telemetry-allocation-followup.md)
completed all six source-app cases, matching 2,045 files each, with 2,322 successful
fixture API requests, 2,304 memory operations and no model calls. Enabled main
matched RSS maxima were 3,145,728/3,186,688 bytes; endings were
2,768,896/2,428,928 bytes. The unchanged 2 MiB gate still fails. Both opted-out
comparisons and all other roles are retained; no causal improvement, resource
pass, budget change or workload replay is claimed.

This batch also records [installed 4.46.22 review-control acceptance](../validation/2026-10-26-telemetry-installed-review.md)
from existing artifacts: five targets in attempt 1 and Mac ARM in its single-job
capacity retry. Eight telemetry fields per target passed, including review-mode
choice and opt-out/manual-mode restart persistence. No new app or model run was
needed to qualify those artifacts. Actual report staging, approval and delivery,
later owners and current-release installed behavior remain outside that scope.

All 66 requirement states remain unchanged. V08 stays **Building and inactive**,
with collection unavailable and destination/route null. Resource, whole-wire,
provider/ingress privacy and installed-platform gates remain open. Publication
and actual PC/VPS upgrades require their separate evidence; current availability
belongs to [release status](../RELEASE_STATUS.md).
