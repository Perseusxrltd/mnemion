# Mnemion 4.11.0

Configure an app-owned workspace's company identity provider from **Setup & this
device → Company sign-in setup**. Studio shows the HTTPS callback, reads and
reviews OIDC provider settings, saves client and certificate configuration,
sets session limits and restarts the local workspace safely. Matching private
agent operations support the same workflow.

- Saved client secrets remain private. Changing a provider or client requires
  explicit secret replacement/removal; stale company or HTTPS settings require
  a fresh review.
- Provider removal and damaged-file repair retain independent local access.
  Existing explicitly configured server environment files are preserved.
- Discovery waits for a harmless readiness read after restart. Recovery-test
  failures now include the existing bounded, secret-free setup diagnostic.

[Validation](../validation/2026-10-15-company-provider-setup.md) records **47
service and 50 desktop checks**, real PostgreSQL/model startup and an actual
Dex/company-invitation browser flow. This source milestone introduces no new
database migration beyond 4.10.0's migration 019. Separately hosted servers still
require their operator's supported configuration and upgrade process.

the [product page](https://www.perseusxr.com/mnemion) identify verified published
