# Mnemion 4.46.7

**Unpublished candidate, superseded by [4.46.8](4.46.8.md).** Native qualification
encountered [Windows and Linux build failures](../validation/2026-10-25-native-build-portability.md).
The corrected 4.46.8 candidate still requires native qualification and publication;
this page preserves the 4.46.7 source changes.

Managed host snapshot and access-ledger commands now wait up to five minutes
for their turn when source scans hold the host lock. Active scans finish
naturally, and new scans defer while capture waits. This addresses repeated
`host_operation_busy` responses during continuous source activity.

After waiting, capture rereads protected settings and credentials, rejects a
change in management mode or the complete active runtime record, and rechecks
snapshot destinations. An unchanged, compatible older runtime remains allowed.
The five-minute bound applies to acquiring the lock, not the complete backup.

This update also includes [product-telemetry source work](../implementation/anonymous-product-telemetry.md)
since 4.46.6, including privacy choices and bounded local processing. Production
collection remains disabled, with no destination or route selected. V08 remains
Building; full resource/platform and collector/ingress privacy qualification are
still open.

Focused PostgreSQL, encryption and lock-coordination checks passed. See the
[validation evidence](../validation/2026-10-25-host-backup-capture.md) and
[current release availability](../RELEASE_STATUS.md).
