# Mnemion 4.46.53

This batch corrects Mac launch compatibility and Windows backup-state reads.
The Mac ad-hoc build explicitly permits its bundled Electron Framework while
keeping hardened runtime enabled. This addresses the Team ID error reported in
[issue 49](https://github.com/Perseusxrltd/mnemion/issues/49); native package
validation and acceptance on the affected Mac remain separate release gates.

On Windows, checking an already-private workspace folder no longer rewrites
its unchanged permissions. That rewrite changed inherited backup-file metadata
and could make a concurrent status read fail. The fix checks current permissions
on every call and still repairs broader permissions. Backup reads retain all
existing integrity checks. Future installed-test failures record only fixed
diagnostic categories, without paths, settings or operating-system error text.

The [Windows qualification](../validation/2026-10-29-windows-directory-security.md)
includes an actual Python/Node regression that failed before the correction.
The [Mac qualification](../validation/2026-10-29-macos-adhoc-launch.md) records
the reported crash, policy change and required native acceptance. Previous
background-update, retrieval and telemetry-report corrections are included.
Published installer availability belongs to [release status](../RELEASE_STATUS.md).
The latest measured public installers, 4.46.49, are about 220–271 MB; the
unchanged 400 MiB download ceiling applies to this batch too.

All 66 requirement states remain unchanged. Issues 44, 47, 48 and 49 remain
open until their full acceptance passes. V08 remains Building and production
telemetry collection remains disabled.
