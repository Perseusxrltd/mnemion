# Mnemion 4.46.2

**23 October 2026 source checkpoint: unreleased.** Public availability requires
the release pipeline's acceptance; current packages and gates remain recorded
in [release status](../RELEASE_STATUS.md). This source hotfix has not passed
installed or actual-host acceptance at this checkpoint.

Native host adoption, backup setup, service start/stop/resolution and upgrade
planning now use the existing supported **five-minute source-drain window**.
They allow active scans to finish while waiting for the operator lock. If a
source still blocks the operation after 300 seconds, the operation records the
fixed `host_busy` outcome; the UI explains the busy-source condition. Active
scans are preserved, and a blocked service action does not change intent or
begin its effect.

The [actual 4.46.1 host-control journey](../validation/2026-10-23-independent-host-adoption.md)
reached successful OS integration and two protected custodian enrollments, then
failed at its first Windows stop. The adapter's 60-second operator-lock wait
expired behind a source scan, before any effect. The original `operation_failed`
receipt remains preserved; no second stop or restart was requested. The
[earlier 4.46.1 paired update](../validation/2026-10-23-4461-live-acceptance.md)
remains accepted.

Two source regressions passed using real lock contention and simulated time:

- A source finishing after **75 simulated seconds** allowed exactly one
  authorized stop.
- A source lease that remained held produced `host_busy` after **300 simulated
  seconds**, with no effect, no intent change and the source scan preserved.

These checks establish the source behavior, not elapsed-time performance or an
installed recovery result. The broader host-control, managed-connector and
custody selection completed with **99 passed and 2 skipped in 90.09 seconds**.
All **six desktop host-profile tests** passed. The web frontend production
build, Electron build and Ruff check also passed. Native/public release gates
and a renewed actual operational journey remain unproven.

Fresh native host-control backup delivery and restore, whole-machine boot,
separate physical-device custody and provider wake remain outside this evidence.
All [66 requirement texts and states](../PRODUCT_REQUIREMENTS.md) are unchanged.
[V08 telemetry](../implementation/anonymous-product-telemetry.md) remains
Planned and inactive, outside this hotfix.
